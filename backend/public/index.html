Kiểm thử 2 Truy vấn Tối ưu hoá

COMPOSITE INDEX + SARGABLE

Hệ thống đã tạo sẵn 2 Composite Covering Index (IDX_GD_VI_NGUON_NGAY_TT, IDX_SC_VI_NGAY_LOAI) trên tập dữ liệu hơn 15.000 giao dịch lịch sử và phân tích Execution Plan trong sql/10_optimization_plans.sql.

  • Truy vấn 1: Thay TRUNC(NGAY_TAO) bằng dải thời gian Sargable + Covering Index → chuyển từ TABLE ACCESS FULL sang INDEX RANGE SCAN.
  • Truy vấn 2: Thay 2 Correlated Subquery trên CHI_TIET_SO_CAI bằng gom nhóm 1 lượt (Conditional Aggregation) + Composite Index.
